# Додзё Медиа — лендинг

Тестовое задание: вёрстка лендинга по макету из Figma («Светлый Дом — Landing 1:1»).

**Демо:** https://saxarov20012310-netizen.github.io/dojo-landing/

## Что сделано

- Десктоп 1440 и мобильная версия 390 по макету, плюс промежуточный вариант для планшета.
- Мобильное меню: открывается и закрывается по кнопке, по клику на пункт и по Esc, закрывается при переходе на десктопную ширину.
- Состояния из макета: hover у кнопок, карточек и ссылок, focus-visible (outline 2px, offset 3px).
- Карточка проекта целиком — одна ссылка, без вложенных кнопок.
- Картинки сжаты в WebP с запасным JPG, ниже первого экрана грузятся лениво.

## Стек

HTML, CSS, немного JavaScript — без фреймворков и сборки. Шрифты Oranienbaum и Manrope подключены с Google Fonts.

```
index.html
css/style.css   — токены из макета в CSS-переменных, блоки по BEM
js/menu.js      — мобильное меню
img/            — картинки и иконки из макета
```

## Как запустить

Открыть `index.html` в браузере или поднять любой статический сервер:

```
python -m http.server 8000
```

## Инструменты

Вёрстку делал с помощью ИИ-ассистента Claude Code (Anthropic). Макет читал через Figma MCP: оттуда брал размеры, шрифты, цвета и картинки. Соответствие макету, адаптив и состояния элементов проверял сам в браузере на ширинах 1440, 820 и 390.
